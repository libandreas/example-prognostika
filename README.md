# Example Προγνωστικά

Το Example Προγνωστικά είναι μια εφαρμογή PHP για καταχώριση, παρουσίαση και παρακολούθηση αθλητικών προγνωστικών. Συνδέει τη δουλειά του συντάκτη με αυτό που βλέπει ο επισκέπτης: από την προσθήκη ενός δελτίου μέχρι το αποτέλεσμα του αγώνα, το ιστορικό και τη συνολική στατιστική εικόνα.

Το project παρουσιάζεται εδώ ως δείγμα παλαιότερης δουλειάς μου στην ανάπτυξη εφαρμογών web. Περιλαμβάνει φόρμες διαχείρισης, πίνακες προγνωστικών, υπολογισμούς απόδοσης, διαχείριση χρηστών και περιόδων συνδρομής, καθώς και προβολές που μπορούν να ενσωματωθούν σε άλλη ιστοσελίδα.

## Σκοπός του project

Η εφαρμογή καλύπτει την ανάγκη μιας ιστοσελίδας προγνωστικών να οργανώνει τις επιλογές πολλών συντακτών με κοινή μορφή. Κάθε επιλογή χρειάζεται συγκεκριμένα στοιχεία αγώνα, αγορά, απόδοση και ποντάρισμα, ενώ μετά την ολοκλήρωσή της πρέπει να παραμένει διαθέσιμη στο ιστορικό.

Οι πίνακες συγκεντρώνουν αυτά τα στοιχεία ώστε ο αναγνώστης να βλέπει τι έχει προταθεί, τι παραμένει ανοιχτό και ποια είναι η πορεία κάθε συντάκτη. Οι στατιστικές προβολές επιτρέπουν την εξέταση της δραστηριότητας ανά περίοδο και κατηγορία.

Η ίδια πληροφορία αξιοποιείται τόσο στο κέντρο διαχείρισης όσο και στη δημόσια παρουσίαση. Αυτό εξυπηρετεί τη συντήρηση των προγνωστικών και τη δημοσίευσή τους σε μία ή περισσότερες σελίδες.

## Βασικές δυνατότητες

- Ξεχωριστά προφίλ συντακτών προγνωστικών, με δικές τους εγγραφές και στατιστικά.
- Καταχώριση μονών, διπλών και τριπλών δελτίων.
- Επιλογή αθλήματος, χώρας, πρωταθλήματος, αγοράς και στοιχηματικής εταιρείας.
- Στοιχεία ομάδων, ημερομηνίας και ώρας, επιλογής, απόδοσης, πονταρίσματος και περιγραφής.
- Κατηγορίες κανονικών, live και μακροχρόνιων προγνωστικών.
- Κλειδωμένες εγγραφές με έλεγχο πρόσβασης στην προβολή τους.
- Ενημέρωση σκορ και κατάστασης στοιχήματος.
- Ανοιχτά δελτία, ιστορικό και συγκεντρωτικά στατιστικά.
- Διαχείριση χρηστών, καταλόγων επιλογών, σεζόν και περιόδων συνδρομής.
- Ενσωμάτωση πινάκων μέσω iframe και παροχή συγκεντρωτικών δεδομένων μέσω της σελίδας API.

## Η διαδρομή ενός προγνωστικού

1. Ο χρήστης συνδέεται και επιλέγει το προφίλ που διαχειρίζεται.
2. Στη σελίδα `pliromes/todaytips.php` δημιουργεί ένα δελτίο με μία, δύο ή τρεις επιλογές.
3. Συμπληρώνει τα στοιχεία των αγώνων, την αγορά, την επιλογή, την απόδοση και το ποντάρισμα. Μπορεί να προσθέσει περιγραφή και να χαρακτηρίσει το δελτίο ως live, μακροχρόνιο ή κλειδωμένο.
4. Η εγγραφή αποθηκεύεται στον φάκελο του αντίστοιχου χρήστη και εμφανίζεται στις σχετικές προβολές.
5. Μετά τον αγώνα, καταχωρίζονται το αποτέλεσμα και η κατάσταση του στοιχήματος.
6. Οι προβολές ιστορικού και οι υπολογισμοί στατιστικών αξιοποιούν τα αποθηκευμένα στοιχεία.

Το σκορ του αγώνα και η κατάσταση του στοιχήματος είναι διαφορετικά πεδία. Για παράδειγμα, ένα σκορ 2:1 δεν καθορίζει από μόνο του αν κέρδισε μια επιλογή: αυτό εξαρτάται από την αγορά και το σημείο που καταχωρίστηκαν.

## Οι πίνακες και οι σελίδες Today

Ο φάκελος `table/` περιέχει τις σελίδες παρουσίασης. Οι πίνακες είναι προβολές HTML των αποθηκευμένων προγνωστικών και στατιστικών.

| Σελίδα | Χρήση |
| --- | --- |
| `table/todaytips.php` | Κεντρική προβολή προγνωστικών ενός προφίλ, με ανοιχτές επιλογές, ειδικές κατηγορίες και ιστορικό. |
| `table/todaytips-all.php` | Συγκεντρωτική προβολή εγγραφών από διαφορετικούς χρήστες, με επιλογές προβολής ανά άθλημα. |
| `table/statistics.php` | Αναλυτικοί πίνακες στατιστικών του επιλεγμένου προφίλ και της περιόδου. |
| `table/widget-1.php` | Συνοπτικός πίνακας μηνιαίου Profit και Yield για τη σεζόν. |
| `table/tipsters.php` | Συγκεντρωτική παρουσίαση συντακτών και ανοιχτών προγνωστικών. |
| `table/account.php` | Ρυθμίσεις λογαριασμού. |
| `table/api.php` | Έξοδος δεδομένων σε μορφή JSON, με χρήστη και συγκεντρωτικά κέρδη συνολικά και ανά σεζόν. |

Η παράμετρος `u` χρησιμοποιείται για την επιλογή προφίλ. Για παράδειγμα, η διεύθυνση `/table/todaytips.php?u=global` εμφανίζει το αντίστοιχο προφίλ παραδειγμάτων.

Το όνομα Today αφορά την καθημερινή χρήση του πίνακα. Η εφαρμογή περιλαμβάνει επίσης προηγούμενες εγγραφές, ιστορικό και σεζόν.

Υπάρχουν δύο διαφορετικές σελίδες με το όνομα `todaytips.php`:

- Η `pliromes/todaytips.php` είναι η φόρμα καταχώρισης και επεξεργασίας.
- Η `table/todaytips.php` είναι η προβολή των προγνωστικών.

Τα `agora.php`, `xora.php`, `protathlima.php` και `tips.php` του φακέλου `table/` παρέχουν επιλογές στις φόρμες. Έτσι, οι διαθέσιμες αγορές και διοργανώσεις μπορούν να συνδέονται με το άθλημα και τη χώρα που επιλέχθηκαν.

## Στατιστικά

Οι στατιστικοί πίνακες παρουσιάζουν τη δραστηριότητα ανά μήνα, στοιχηματική εταιρεία, άθλημα, πρωτάθλημα και αγορά. Οι σεζόν ορίζουν τα χρονικά διαστήματα συγκέντρωσης των δεδομένων.

| Ένδειξη | Τι παρουσιάζει |
| --- | --- |
| Picks | Πλήθος επιλογών ή εγγραφών σύμφωνα με τον υπολογισμό της συγκεκριμένης προβολής. |
| Win Rate | Ποσοστό κερδισμένων επιλογών. |
| Profit | Καθαρό αποτέλεσμα από πονταρίσματα και επιστροφές. |
| Yield | Σχέση καθαρού αποτελέσματος προς το συνολικό ποντάρισμα. |
| Avg Stake | Μέσο ποντάρισμα. |
| Avg Odds | Μέση απόδοση. |

Οι υπολογισμοί βρίσκονται στον φάκελο `kernel/`. Οι καταστάσεις των δελτίων και των επιμέρους επιλογών χρησιμοποιούνται για τη διάκριση κερδών, ζημιών και επιστροφών. Τα συγκεντρωτικά αποτελέσματα εξαρτώνται από τα δεδομένα που έχουν καταχωριστεί.

## Κέντρο διαχείρισης: pliromes

Ο φάκελος `pliromes/` διατηρεί την παλιά ονομασία του, αλλά περιλαμβάνει το ευρύτερο κέντρο διαχείρισης της εφαρμογής.

| Σελίδα | Αρμοδιότητα |
| --- | --- |
| `todaytips.php` | Προσθήκη και επεξεργασία προγνωστικών. |
| `apotelesmata.php` | Καταχώριση αποτελεσμάτων και κατάστασης στοιχήματος. |
| `todaytips-apot.php` | Επεξεργασία αποθηκευμένων σκορ. |
| `users.php` | Διαχείριση χρηστών, στοιχείων προφίλ, συνδέσμων και καταλόγου σεζόν. |
| `pliromes.php` | Διαχείριση ημερομηνιών και διάρκειας συνδρομών. |
| `athlimata.php` | Κατάλογος αθλημάτων. |
| `xores.php` | Χώρες ανά άθλημα. |
| `protathlimata.php` | Πρωταθλήματα ανά χώρα και άθλημα. |
| `agores.php` | Στοιχηματικές αγορές ανά άθλημα. |
| `eteries.php` | Κατάλογος στοιχηματικών εταιρειών. |

Η σελίδα `pliromes.php` εξυπηρετεί τη διαχείριση συνδρομητικών περιόδων, όπως ημερομηνία έναρξης και λήξης. Δεν τεκμηριώνεται εδώ ως υπηρεσία αυτόματης ηλεκτρονικής χρέωσης.

Οι σελίδες διαχείρισης χρησιμοποιούν τα στοιχεία του συνδεδεμένου χρήστη για τον έλεγχο πρόσβασης. Οι λειτουργίες διαχειριστή και οι λειτουργίες ενός συντάκτη διακρίνονται στον κώδικα των αντίστοιχων σελίδων.

## Οργάνωση κώδικα και δεδομένων

| Φάκελος | Ρόλος |
| --- | --- |
| `table/` | Παρουσίαση προγνωστικών, ιστορικού, στατιστικών και δεδομένων API. |
| `pliromes/` | Φόρμες καταχώρισης και κέντρο διαχείρισης. |
| `kernel/` | Λογική εφαρμογής, ανάγνωση και αποθήκευση εγγραφών, ομαδοποιήσεις και υπολογισμοί. |
| `users/` | Αρχεία προφίλ, προγνωστικών και κοινών καταλόγων. |
| `common/` | Κοινές συναρτήσεις PHP και JavaScript, υποστήριξη φορμών και ενσωμάτωσης. |
| `css/`, `js/` | Συνοδευτικά styles και JavaScript βιβλιοθήκες. |
| `images/`, `flags/` | Εικόνες παρουσίασης και σημαίες χωρών. |

### Kernel

- Το `kost-kernel.php` προετοιμάζει το περιβάλλον της εφαρμογής, όπως τον επιλεγμένο χρήστη, τη σύνδεση και τη σεζόν.
- Το `kost-gui.php` συγκεντρώνει εγγραφές για προβολή, δημιουργεί ομάδες δεδομένων και χειρίζεται αποθηκεύσεις προγνωστικών και αποτελεσμάτων.
- Το `kost-tables.php` διαβάζει τα πεδία μιας εγγραφής και προετοιμάζει τις μεταβλητές που χρησιμοποιούν οι πίνακες.
- Τα `kost-calcs.php` και `kost-calcs-new.php` περιέχουν συναρτήσεις υπολογισμού και επεξεργασίας στατιστικών.
- Το `kost-calcs-season.php` συγκεντρώνει υπολογισμούς ανά σεζόν.
- Το `kost-html.php` περιέχει συναρτήσεις παραγωγής επαναλαμβανόμενων στοιχείων HTML.
- Το `kost-cleaner.php` είναι ξεχωριστό εργαλείο καθαρισμού παλαιότερων παραγόμενων αρχείων, όχι βήμα εγκατάστασης.

### Αποθήκευση σε αρχεία

Τα βασικά δεδομένα προγνωστικών αποθηκεύονται σε φακέλους και αρχεία κειμένου, χωρίς σχεσιακή βάση δεδομένων για αυτές τις εγγραφές.

Μια εγγραφή ακολουθεί τη δομή:

```text
users/
  example-user/
    info/
      1/
    tips/
      20261023120000/
        athlima.txt
        xora.txt
        protathlima.txt
        omada1.txt
        omada2.txt
        agora.txt
        tips.txt
        odds.txt
        posoA.txt
        per.txt
```

Το παράδειγμα δείχνει μέρος των πεδίων. Υπάρχουν επίσης αρχεία ημερομηνίας, ώρας, αποτελέσματος και κατάστασης. Για διπλά και τριπλά δελτία χρησιμοποιούνται πρόσθετα πεδία με προθέματα `D` και `T`.

Ο φάκελος `users/global/` περιέχει κοινούς καταλόγους, όπως αθλήματα, χώρες, πρωταθλήματα και αγορές. Χρησιμοποιείται επίσης για παραδείγματα προγνωστικών. Όπου μια εγγραφή χαρακτηρίζεται ως δοκιμαστική, οι ημερομηνίες, οι αποδόσεις και τα σκορ της είναι ενδεικτικά.

## Εκτέλεση και ενσωμάτωση

Η εφαρμογή εκτελείται σε web server με PHP. Η ρίζα του project πρέπει να είναι το document root, επειδή οι σελίδες χρησιμοποιούν διαδρομές όπως `/common/`, `/table/` και `/users/`.

Για την προετοιμασία του περιβάλλοντος χρειάζονται:

1. PHP με τις συναρτήσεις που χρησιμοποιεί ο κώδικας και τα κοινά αρχεία του φακέλου `common/`. Χρησιμοποιούνται και συναρτήσεις της PHP 8, όπως `str_contains`.
2. Δικαιώματα ανάγνωσης και εγγραφής της PHP στους φακέλους δεδομένων που ενημερώνει η εφαρμογή.
3. Οι κοινοί κατάλογοι του `users/global/`, μαζί με τον κατάλογο σεζόν.
4. Ρυθμισμένος λογαριασμός για πρόσβαση στο κέντρο διαχείρισης.

Η σελίδα `index.php` παρέχει τη σύνδεση και η `users/index.php` την επιλογή προφίλ. Το project παρουσιάζει την υπάρχουσα εφαρμογή και δεν περιλαμβάνει οδηγό αυτόματης εγκατάστασης.

### Ενσωμάτωση πινάκων σε άλλη σελίδα

Το `example-to-embed.html` δείχνει την ενσωμάτωση του πίνακα προγνωστικών σε iframe. Η διεύθυνση μπορεί να δείχνει στην εγκατάσταση της εφαρμογής και να επιλέγει συγκεκριμένο προφίλ:

```html
<iframe
  src="https://example.com/table/todaytips.php?u=global"
  title="Example Προγνωστικά"
  style="width: 100%; height: 700px; border: 0;">
</iframe>
```

Τα κοινά scripts περιλαμβάνουν υποστήριξη προσαρμογής του ύψους των iframe. Για αυτή τη συμπεριφορά χρησιμοποιείται το αντίστοιχο παράδειγμα ενσωμάτωσης του project.

## Συνοδευτικά εργαλεία

### CKEditor

Ο CKEditor χρησιμοποιείται για μορφοποιημένο κείμενο στο πεδίο περιγραφής της φόρμας `pliromes/todaytips.php`. Η υπάρχουσα εγκατάσταση του project βασίζεται στο CKEditor 4.21.0.

Για την προσθήκη του, τοποθετήστε τα αρχεία του CKEditor 4 στον φάκελο `ckeditor/`, ώστε το κύριο script να βρίσκεται στο `ckeditor/ckeditor.js`. Η φόρμα το φορτώνει όταν υπάρχει. Χωρίς αυτό, η περιγραφή επεξεργάζεται σε απλό πεδίο κειμένου.

### Simple File Manager και Simple PHP Captcha

Το Simple File Manager χρησιμοποιείται για διαχείριση αρχείων από το περιβάλλον του διαχειριστή.

Το Simple PHP Captcha χρησιμοποιείται για έλεγχο ανθρώπινης υποβολής στη φόρμα σύνδεσης. Χρειάζεται τα συνοδευτικά αρχεία εικόνας και γραμματοσειράς, καθώς και PHP GD με υποστήριξη PNG και FreeType.

### Προαιρετικά SPA και TTFB

Στο παρελθόν χρησιμοποιούσα τα SPA και TTFB στην εφαρμογή για τη βελτίωση της εμπειρίας πλοήγησης και της απόδοσης.

Το SPA προσθέτει πλοήγηση με JavaScript, ενώ το TTFB αφορά τη διαχείριση προσωρινής αποθήκευσης και χρόνου απόκρισης. Η βασική εφαρμογή διαθέτει κανονικές σελίδες PHP και μπορεί να χρησιμοποιηθεί χωρίς αυτά.

Όποιος θέλει μπορεί να τα ενσωματώσει προαιρετικά από το ξεχωριστό repository [php-page-cache](https://github.com/libandreas/php-page-cache). Τα αντίστοιχα ζεύγη αρχείων είναι:

- `common/spa.php` και `common/spa.js`.
- `common/ttfb.php` και `common/ttfb.js`.

Οι σελίδες της εφαρμογής φορτώνουν τα PHP αρχεία όταν υπάρχουν. Για πλήρη ενσωμάτωση χρειάζονται και τα αντίστοιχα JavaScript αρχεία, μαζί με τις εξαρτήσεις και τη ρύθμιση που περιγράφονται στο repository του εργαλείου.

## Τι παρουσιάζει ως project
